  • An edge joins two nodes and stands for a relationship between them: a road, a friendship, a link.

Step 2 of 4

Direction: is A–B the same as B–A?

The kernel says
Kernel check.
  • In an undirected graph an edge has no direction. A–B and B–A are the same edge, like a friendship.
  • In a directed graph each edge points one way. A→B and B→A are two edges, like following someone.
  • Directed edges can carry different weights each way: uphill A→B takes 20 minutes, downhill B→A takes 12.

Step 3 of 4

How many edges can K nodes have?

The kernel says
Kernel check.
  • When every node joins every other node the graph is complete. That is the most edges a simple graph can have.
  • Each new node joins all the nodes already there, so totals grow 1, 3, 6, 10, 15: the triangular numbers.
  • Undirected maximum is K(K−1)/2. Directed maximum is K(K−1). The fewest edges that keep K nodes connected is K−1, a tree.

Step 4 of 4

Many weighted edges between the same nodes

The kernel says
Kernel check.
  • A weight is a number on an edge: distance, time, cost or capacity.
  • Parallel edges join the same two nodes. A graph that allows them is a multigraph, and then K(K−1)/2 no longer limits the edge count.
  • Shortest paths keep only the lightest parallel edge. Flow problems add capacities together. Counting routes keeps every edge.
